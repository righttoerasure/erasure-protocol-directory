# 🛡️ The Erasure Protocol Directory

An open-source, aggregated database of official data deletion and opt-out links for hundreds of global companies, data brokers, and tech platforms.

## 🌐 The Live Vault
To use the interactive, searchable, and constantly updated directory, please visit our official website:
**👉 [Right To Erasure (righttoerasure.org)](https://righttoerasure.org)**

## 📦 About This Repository
The modern internet is designed to make data deletion notoriously difficult through "Dark Patterns." Finding the exact page to delete an account or opt-out of data selling is intentionally buried by corporations. 

This repository serves as the raw, open-source dataset (`erasure-protocol-master.csv`) powering the Right To Erasure directory. We believe that privacy is a fundamental human right, and the tools to enforce it should be free, open, and accessible to everyone.

### What's inside the CSV?
* **Company Name**
* **Root Domain** (Unique Identifier)
* **Category** (Data Brokers, Tech, Retail, etc.)
* **Difficulty Level** (Easy, Medium, Hard)
* **Official Deletion/Privacy URL**
